## Generated game output

C and header files generated for a game project by Rohr Engine are explicitly
excluded from Rohr Engine's LGPL-3.0-only licensing terms. They carry this
notice:

```c
/*
 * Generated by Rohr Engine.
 * This generated file is not covered by Rohr Engine's LGPL-3.0-only license.
 * The project's developer may use, modify, and distribute it without restriction.
 */
```

This exclusion applies to generated game output, not to Rohr Engine library or
tool source copied or modified by a project.

## Static linking

The current SDK exports Rohr as a static library. Distributors of a combined
application must follow LGPLv3 section 4, including the required notices and a
practical way for recipients to relink the application with a modified Rohr
library. A future shared-library SDK will provide the simpler replacement
mechanism described by that section.
